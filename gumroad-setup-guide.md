# Gumroad Setup Guide for Blueprint

## Quick Setup (10 minutes)

### 1. Create Your Gumroad Account
- Go to [gumroad.com](https://gumroad.com)
- Sign up with your email
- Verify your account

### 2. Create The Blueprint Product

**Click "New Product" → "Digital Product"**

Fill in these details:

**Product Info:**
- Name: `The Complete Blueprint System`
- Price: `$888`
- URL slug: `blueprint` (so your link is clean)

**Description (copy/paste this):**
```
Get all 67 battle-tested documents from $80M+ in service business deals.

✓ 25 Acquisition Documents - Find and buy businesses with little money down
✓ 22 Operations Systems - Run everything remotely in 15 hrs/week
✓ 10 Empire Building Strategies - Scale to multiple businesses
✓ 10 Bonus Templates - Contracts, scripts, and frameworks

Instant download after purchase.

This is the same system I used to build a portfolio of boring service businesses.

Note: If you downloaded the free Starter Pack, use code STARTERPACK for $191 off.
```

**Upload Your Files:**
- Create a ZIP file with all 67 documents
- Name it: `Blueprint-Complete-System.zip`
- Upload to Gumroad

### 3. Create the Discount Code

1. Go to your product dashboard
2. Click "Offer codes"
3. Create new offer code:
   - Code: `STARTERPACK`
   - Discount type: "Amount off"
   - Discount amount: `$191`
   - Uses: Unlimited
   - Active: Yes

### 4. Update Your Website

The code is already updated! Just replace `myleskameron` with your actual Gumroad username in:
```
https://myleskameron.gumroad.com/l/blueprint
```

### 5. Test Everything

1. Visit: http://localhost:3001/blueprint-special
2. Click the payment button
3. Verify:
   - Gumroad overlay appears
   - Price shows $697 (discounted from $888)
   - Checkout works smoothly

### 6. Settings to Configure

**Payment Settings:**
- Add your bank account for payouts
- Set up tax settings if needed

**Email Settings:**
- Customize purchase receipt email
- Add thank you message

**Analytics:**
- Install Facebook Pixel (optional)
- Set up Google Analytics (optional)

## What Happens When Someone Buys:

1. Customer clicks button on your site
2. Gumroad overlay appears
3. They enter payment info
4. After payment:
   - They get instant download link
   - Email receipt sent
   - You get notification
   - Money hits your account (minus 5% + $0.30)
